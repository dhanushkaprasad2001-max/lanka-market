# LankaMarket

A mobile-friendly Sri Lankan classifieds marketplace frontend.

## Current prototype
- Responsive homepage and category browsing
- Search by keyword and filter by category/district
- Sort listings by price
- Demo ad-posting form
- Demo ads are saved in the current browser using localStorage

## Important
This is currently a **frontend prototype**, not yet a public multi-user marketplace. Listings created in the form are saved only in the browser/device that created them. Phone numbers are not displayed publicly yet. There is no secure login, shared database, cloud image upload, moderation dashboard, or payment system yet.

Before accepting real public listings, connect a backend such as Supabase (authentication, database, and image storage), add server-side validation and admin moderation, and publish privacy/terms/safety pages. Never put private service-role keys in frontend code.

## Enable GitHub Pages
1. Open the repository Settings.
2. Open Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for the deployment, then open the Pages URL shown there.
